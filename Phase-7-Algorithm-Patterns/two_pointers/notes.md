# Phase 7 - Algorithm Patterns

## What is it?

Patterns are recurring problem-solving approaches that work for many different problems.

**Master these 5 patterns:**
1. **Two Pointers** - Meeting in the middle
2. **Sliding Window** - Fixed/dynamic window on array
3. **Fast & Slow Pointers** - Linked list detection
4. **Dynamic Programming** - Break into subproblems, memoize
5. **Backtracking** - Explore all possibilities

---

## Why does it matter?

**Real-world reasons:**
1. **Time saver** - Know pattern = solve faster
2. **Interview essential** - 60% of questions use patterns
3. **Transferable** - Learn once, apply many times
4. **Confidence builder** - Problems become predictable
5. **Efficient** - Patterns are optimized approaches

---

## Pattern Summary

```
Two Pointers:      Sort → use pointers from both ends
Sliding Window:    Maintain window of valid elements
Fast/Slow:         Detect cycles, find middle
DP:                Overlapping subproblems, memoize
Backtracking:      Explore all branches, mark/unmark
```
