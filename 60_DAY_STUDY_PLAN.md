# 60-Day DSA Mastery Study Plan

**Goal**: Master DSA from basics to interview-ready  
**Time Commitment**: 2-3 hours per day, 5 days per week  
**Total Weeks**: 12 weeks (60 days of actual studying)

---

## **How to Use This Plan**

1. **Follow the schedule** - Stick to the weekly theme
2. **Daily: 2-3 hours**
   - 30 min: Read theory
   - 60 min: Code examples + exercises
   - 30-60 min: LeetCode problems
3. **Weekly: Review** - Spend Friday reviewing the week
4. **Flexible**: If you need more time on a phase, take it!
