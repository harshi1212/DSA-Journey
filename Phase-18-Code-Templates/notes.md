# Phase 18 - Code Templates (Copy-Paste Ready)

## What Are Templates?

Production-ready code snippets for common algorithms.

**Time saved**: 30% faster in real interviews

**How to use**: Copy → Modify → Test

---

## Template Categories

1. **Data Structures**: Union-Find, Segment Tree, Fenwick Tree
2. **Graph Algorithms**: BFS, DFS, Dijkstra, Floyd-Warshall
3. **String Algorithms**: KMP, Z-algorithm, Rabin-Karp
4. **DP Templates**: Knapsack, LIS, Coin Change
5. **Search Templates**: Binary Search, DFS, BFS
6. **Math Templates**: GCD, Modular arithmetic

---

## When Templates Help Most

- Interview: Copy template, focus on logic
- Practice: Understand internals
- Competition: Use for speed

---

## Study Strategy

1. Read one template
2. Understand every line
3. Code from memory
4. Use in problem
5. Repeat until second nature
