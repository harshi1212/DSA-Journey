# Phase 6 - Algorithms

## What is it?

Algorithms are step-by-step procedures to solve problems.

**Core algorithms to master:**
- **Recursion** - Function calling itself
- **Searching** - Linear, binary search
- **Sorting** - Bubble, merge, quick sort

---

## Why does it matter?

**Real-world reasons:**
1. **Foundation for all DSA** - Everything builds on these
2. **Interview backbone** - 50% of questions use these
3. **Performance critical** - Sorting can make or break systems
4. **Real-world use** - Every program sorts, searches, and recurses
5. **Problem solving skill** - Learn to break problems down

---

## Key Topics

```
Recursion:  Base case + recursive case, exponential costs
Searching:  Linear O(n), Binary O(log n)
Sorting:    Bubble O(n²), Merge O(n log n), Quick O(n log n)
```
