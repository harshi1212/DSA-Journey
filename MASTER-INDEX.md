## Quick Reference

### Complexity Cheat Sheet

| Operation | Complexity | Notes |
|-----------|-----------|-------|
| Array access | O(1) | Direct index |
| Array insert/delete | O(n) | May need shift |
| Hash map lookup | O(1) | avg case |
| Hash map insert | O(1) | amortized |
| Set operations | O(1) | avg case |
| Linked list access | O(n) | Must traverse |
| Linked list insert | O(1) | At known position |
| Binary search | O(log n) | Requires sorted |
| Sort | O(n log n) | Best case |
| BFS/DFS | O(V+E) | Graph traversal |
| Dijkstra | O((V+E) log V) | Weighted shortest path |
| Binary tree search | O(log n) | Balanced tree |
