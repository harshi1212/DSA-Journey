# Phase 5.5 - Trees

## What is it?

A tree is a hierarchical data structure with a root and branches.

```
       Root
      /    \
    Left   Right
    / \
   L   R
```

Why study them?
- Represent hierarchical data (file system, DOM)
- Foundation for advanced trees (BST, AVL, Red-Black)
- Recursion naturally fits trees
- Interview essential

---

## Why does it matter?

**Real-world reasons:**
1. **File systems** - Folder hierarchy
2. **DOM trees** - HTML structure
3. **Compilers** - Parse trees
4. **Database indexes** - B-trees
5. **Interview critical** - 25% of problems involve trees
