# Phase 5.3 - Stacks and Queues

## What is it?

**Stack** - Last In First Out (LIFO)
- Think: Browser back button (last page visited)
- Operations: push (add), pop (remove top), peek (see top)

**Queue** - First In First Out (FIFO)
- Think: Line at a shop (first person served first)
- Operations: enqueue (add back), dequeue (remove front), peek (see front)

---

## Why does it matter?

**Real-world reasons:**
1. **Browser navigation** - Back button uses stack
2. **Undo/Redo** - Stack of actions
3. **Message queues** - Processing tasks in order
4. **CPU scheduling** - Queue of processes
5. **Interview questions** - Parenthesis matching, decimal to binary
