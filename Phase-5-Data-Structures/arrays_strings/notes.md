# Phase 5.1 - Arrays and Strings

## What is it?

Arrays and strings are the most basic data structures, and also the most common in interviews.

- **Array** → Ordered list of items, fixed or dynamic size
- **String** → Array of characters

Why study them?
- First thing you learn
- Every problem uses arrays
- Most interview questions use arrays
- Foundation for all other data structures

---

## Why does it matter?

**Real-world reasons:**
1. **Every program uses arrays** - Storing lists of data
2. **Interview staple** - 70% of problems involve arrays
3. **Cache efficient** - Contiguous memory is fast
4. **Foundation** - Other data structures build on arrays
5. **String processing** - Text parsing, validation, manipulation

---

## Common Array/String Problems

```
Searching:     Linear search, binary search
Sorting:       Various patterns
Two pointers:  Meeting in middle, comparison
Sliding window: Subarray problems
Transformation: Reverse, rotate, rearrange
```
