# Phase 5.2 - Hash Maps

## What is it?

A hash map (dictionary in Python) stores KEY → VALUE pairs.
- **Key** → Unique identifier (like dictionary word)
- **Value** → Associated data (like definition)

Why study them?
- O(1) lookup, insert, delete
- Most common data structure after arrays
- Solve many problems with hash maps

---

## Why does it matter?

**Real-world reasons:**
1. **Lightning fast lookups** - O(1) instead of O(n)
2. **Frequency counting** - How many of each item?
3. **Caching** - Store computed results
4. **Deduplication** - Find duplicates/unique items
5. **Interview favorite** - 40% of interview problems use hash maps

---

## Common Hash Map Problems

```
Counting frequencies: How many of each?
Finding duplicates: Seen this before?
Grouping similar items: Put related items together
Complement problems: Given x, find y where f(x,y) = target
```
