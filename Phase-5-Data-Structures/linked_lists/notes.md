# Phase 5.4 - Linked Lists

## What is it?

A linked list is a chain of nodes, each pointing to the next.

```
Node: [Data | Next Pointer]

List: [1|→] → [2|→] → [3|→] → [4|None]
```

Why study them?
- Foundation for advanced structures
- Different from arrays (no indexing)
- Memory efficient for dynamic lists
- Interview favorite

---

## Why does it matter?

**Real-world reasons:**
1. **Dynamic data** - Grows/shrinks easily (unlike fixed arrays)
2. **Efficient insertion/deletion** - O(1) in middle (vs O(n) for arrays)
3. **LRU caches** - Used in real systems
4. **Interview standard** - 20% of problems involve linked lists
5. **Memory efficient** - No wasted space like dynamic arrays
