# Phase 13 - Advanced Data Structures

## What Are Advanced Data Structures?

Specialized data structures that solve specific problems efficiently.

---

## Master These 3 Advanced DS

| Data Structure | Purpose | Complexity | Use Case |
|---|---|---|---|
| **Union-Find** | Detect connectivity | Nearly O(1)* | Graphs, friend circles, connected components |
| **Segment Tree** | Range queries/updates | O(log n) | Sum/min/max over range, dynamic updates |
| **Trie Advanced** | Pattern matching | O(m)** | Autocomplete, spell check, IP routing |

*Nearly O(1) with path compression and union by rank  
**m = length of string

---

## Real-World Uses

**Union-Find**:
- Detect cycles in graphs
- Social networks (connected friends)
- Computer networks (reachability)

**Segment Tree**:
- Database range queries
- Stock price ranges
- Cumulative frequency analysis

**Trie Advanced**:
- Search suggestions
- IP routing
- Spell correction
