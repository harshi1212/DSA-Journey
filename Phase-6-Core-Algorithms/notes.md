# Phase 6 — Core Algorithms

## What this phase covers
Searching and sorting algorithms — the most 
fundamental algorithms every developer must know.
This phase has 3 sections:
- Recursion — functions calling themselves
- Searching — finding elements efficiently
- Sorting — arranging data in order

## How to use this phase
1. Start with recursion/ folder
2. Then searching/ folder  
3. Then sorting/ folder
4. Run every .py file and understand the output
5. Check CHECKLIST at the end

## Why algorithms matter
These are the building blocks of every program.
Binary search powers every search bar.
Merge sort runs inside Python's built-in sort.
Recursion is the foundation of trees and graphs.
