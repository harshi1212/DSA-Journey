## Problem-Solving Strategy by Category

### When to Use Two Pointers
- Sorted array, find pair
- Need to avoid nested loops
- Must preserve indices
- Palindrome checking

### When to Use Sliding Window
- Substring/subarray problem
- Contiguous elements
- Expanding/contracting condition
- Fixed or variable window size

### When to Use Binary Search
- SORTED array (must verify!)
- Find exact value or boundary
- Range queries
- Can eliminate half each iteration

### When to Use Dynamic Programming
- Overlapping subproblems
- Optimal substructure
- Can memoize results
- Recurrence relation exists

### When to Use Backtracking
- Generate all possibilities
- Constraint satisfaction
- Need to explore all branches
- Can prune early

### When to Use BFS/DFS
- Tree/graph traversal
- Shortest path (BFS)
- Connected components (DFS)
- Topological sort (DFS)

### When to Use Greedy
- Local optimal leads to global
- Can't change previous choices
- Problem has greedy choice property
- Usually for optimization
